All leaderboards

Players see the boards on the title screen's Leaderboards page. Each board is read at one difficulty at a time (switching it off hides every difficulty of it). Admins never appear on them; banned players drop off. Switching a board off hides it from everyone (its runs are kept).

What players can see

Live: every player sees and can use it. Admin only: only admins see it (the game marks it ADMIN ONLY for you); for players it is not on any menu, not in the bestiary or on the leaderboards, and the server refuses it (a page, a run, a co-op session). Players see a change on their next page load; a co-op session already under way plays on. At least one map always stays live, and so does one way to host co-op.
Players see the version in the bottom-right corner of the game, so a screenshot or a video says which build it is from.
